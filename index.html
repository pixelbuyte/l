A reference corpus

People do not write the way machines write.

This is a collection of ordinary human prose — invoices chased, radiators bled, pianos given away — annotated line by line with what makes each passage read as though a person wrote it. Alongside it sits a library of the habits that give unedited machine prose away, and the measurements that tell the two apart.

Every number on this page is computed in your browser from the passages below. Nothing is hand-entered, so you can check any figure by reading the text it came from.

Measurement

What actually separates them

Each row compares the human corpus on this page against a set of contrast specimens written in the register unedited model output tends to occupy. Both sets are files in this repository; both columns are recomputed every time you load the page.

The verdict column is calculated, not assigned — it is the relative gap between the two figures.

What the contrast set is, and is not

The specimens were written for this project in the style of unedited model output. They were not sampled from any model, and they are not evidence about any particular system. They exist so the comparison is reproducible from files you can read and argue with. Treat the gap as illustrative of a style, not as a measurement of a population.

Method

How this was built, and where it is weak

The passages were written, not scraped

A scraped corpus would be larger and better evidence. It could not be republished cleanly, and the annotations could not quote exact spans without reproducing someone else's paragraph in full. What matters for the argument is the shape of the writing — how the sentences vary, where the concrete nouns sit — and shape survives the substitution. It is still a real limitation, and it is the first thing to fix if this were to become evidence rather than illustration.

The pattern library is curated

The 169 entries are collected from observation, not from a frequency count over a matched pair of corpora. Severity is a judgement. Where an entry says a habit is “more common in machine prose”, read that as a claim about register that you can check against the passages here, not as a measured rate.

Every statistic is recomputed live

Sentence splitting, syllable counting and the rest run in js/metrics.js against the raw passage strings. The same code measures the corpus, the contrast set, and anything you paste into the rewriter, so the three are always comparable. Sentence splitting handles abbreviations, decimals and quotations, and still gets some things wrong.

None of this detects anything

These measurements describe a register. They do not identify an author, and a low burstiness score is not evidence that a person did not write something — plenty of careful human writing is even and plain. Anyone using numbers like these to accuse a student or a colleague is misusing them.
